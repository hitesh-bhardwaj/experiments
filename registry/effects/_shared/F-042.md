# F-042 - Suspend continuous rAF when tab-hidden or offscreen

**Status:** Complete (Tasks 0–5)  
**Severity / goal:** Pause continuous `requestAnimationFrame` (and equivalent engine loops) when:

1. the browser tab is hidden (`visibilitychange` / `document.hidden`)
2. the effect root is offscreen (`IntersectionObserver`, `rootMargin: "256px"` - same idea as `border-beam`)

Resume cleanly when the tab is visible again and the effect is back in (or near) view.

**Constraints:** No UI / responsiveness / registry-behavior changes (`CHANGE_GUIDELINES.md`).

---

## Approach

### Shared utility

Canonical source:

- `registry/effects/_shared/createSuspendedRaf.js`
- Tests: `registry/effects/_shared/createSuspendedRaf.test.js`
- Docs lib copy: `vault-main/src/lib/createSuspendedRaf.js`

**APIs:**

| API | Use when |
|-----|----------|
| `createSuspendedRaf` | You own a simple rAF loop - pass `onFrame`, call `start()` / `destroy()` |
| `createVisibilityGate` | Engine already owns the loop (R3F `frameloop`, GSAP ticker, etc.) - pause/resume via `onChange` |

### Adoption rule (registry packages)

CLI installs one package at a time - consumers **cannot** import `_shared/`. For each effect:

1. Copy `createSuspendedRaf.js` into the package folder
2. List it in that package’s `registry.json` `files`
3. Import from `./createSuspendedRaf`

Docs demos get the same local copy under `vault-main/src/components/<effect>/`.

## How to verify

### Automated

```bash
node --test registry/effects/_shared/createSuspendedRaf.test.js
```

### Manual (browser)

1. Run docs app and open a demo (e.g. `/demo/fractal-glass`)
2. Hide the tab → animation / rAF should stop
3. Return to tab → resume
4. Scroll the effect fully off-screen → pause
5. Scroll back into view → resume

**Smoke set (one per pattern):**

- Raw rAF: `/demo/fractal-glass`
- R3F `frameloop`: `/demo/donut-particles`
- GSAP ticker: `/demo/file-encryption` or `/demo/draggable-marquee`
- Cursor: `/demo/noise-ripple-cursor`
- Background: `/demo/dither-canvas`
- Scroll: `/demo/scroll-distortion`
